# PaladinsRP — site officiel

Site vitrine du serveur GTA RP PaladinsRP, publié avec GitHub Pages.

- `index.html` : accueil (présentation, atouts, systèmes exclusifs)
- `reglement.html` : règlement
- `assets/` : styles, script d'animation (GSAP + ScrollTrigger + Lenis) et images

Aucune compilation : modifier les fichiers puis pousser sur `main`.
